# Job Description Skill Mapping Matrix: Content Safety Analyst

The table below demonstrates how every phase of this project operationalizes the explicit qualifications, responsibilities, and technical requirements listed in the Google Ads Content Safety Analyst job description.

| Job Description Requirement | Project Phase / Deliverable | Demonstrated Proficiency |
| --- | --- | --- |
| **"4+ years experience in data analytics, Trust and Safety, policy, cybersecurity..."** | Phase 2 & 3: BigQuery SQL & Python Statistical Modeling | End-to-end threat detection, SQL wrangling, feature engineering, and network fraud clustering. |
| **"Execute complex queries and analyses, build visual models..."** | SQL Query 01 & 02, Looker Studio Dashboard Specs | Writing multi-CTE SQL scripts (Window Functions, CTEs) to uncover obfuscated fraud rings and visualizing ecosystem risk. |
| **"Conduct investigations to catch fraudsters... learn scam patterns/trends..."** | Forensic Querying & Executive Summary | Identification of ephemeral domain cycling, synthetic ad copy manipulation, and IP subnet clustering. |
| **"Identify automation and efficiency opportunities..."** | Python Script 02: Z-Score Statistical Risk Scoring | Converting manual queue review logic into an automated algorithmic risk-scoring pipeline. |
| **"Collaborate with cross-functional groups (PM, Eng, Sales, Legal)..."** | Executive Summary & RACI Matrix | Translating technical fraud metrics into strategic trade-off proposals balancing safety and advertiser experience. |
| **"Provide periodic on-call coverage and address escalations..."** | SLA & Escalation Framework | Defining SLA-tiering mechanisms (P0/P1/P2) for brand safety, political, and financial scam threats. |
| **"Be exposed to some adult content and other potentially disturbing material..."** | Project Disclaimer & Operational Guardrails | Establishing handling protocols and psychological resilience guardrails for high-severity queues. |
